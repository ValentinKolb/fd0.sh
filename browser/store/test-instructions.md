# Chrome Web Store reviewer instructions

fd0 requires the local Desktop app or CLI; no test account is needed. Install
from https://fd0.sh/#install, create or unlock a local vault, then add a login
whose website matches an HTTPS test page. Focus its username or password field,
click the fd0 icon, and choose the login; the form fills but is never
submitted. Password tools generate and explicitly save or update logins.
Hosted sync is optional.
